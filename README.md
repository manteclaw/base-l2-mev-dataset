# Base L2 MEV Opportunity Dataset

Real-time MEV (Miner Extractable Value) opportunity data from Base Layer 2 decentralized exchanges.

## What's Inside

This dataset contains simulated MEV opportunities across major Base L2 DEXs including Aerodrome, Uniswap V3, and AlienBase. Each record represents a potential arbitrage, liquidation, or JIT liquidity opportunity.

## Use Cases

- **Quantitative Strategy Research**: Backtest MEV extraction strategies
- **Gas Optimization**: Analyze gas cost vs profit tradeoffs
- **Latency Analysis**: Study the impact of RPC latency on profitability
- **Academic Research**: Understand MEV dynamics on L2 chains

## Schema

| Field | Type | Description |
|-------|------|-------------|
| id | string | Unique opportunity ID |
| timestamp | ISO 8601 | When the opportunity was detected |
| pair | string | Trading pair (e.g., WETH/USDC) |
| strategy | string | MEV strategy type |
| dex_buy | string | DEX with lower price |
| dex_sell | string | DEX with higher price |
| price_buy | float | Buy price in USD |
| price_sell | float | Sell price in USD |
| gas_cost_usd | float | Estimated gas cost |
| profit_bps | float | Profit in basis points |
| latency_ms | int | Detection-to-execution latency |
| profitable | bool | Whether opportunity is net profitable |
| block_number | int | Base L2 block number |
